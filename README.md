🔐 Login Security Monitor

A Python-based login security project that demonstrates authentication, login attempt tracking, input validation, and basic account-blocking logic.

🚀 Features
User authentication with predefined demo credentials
Individual login attempt tracking for each user
Warnings when login attempts become low
Temporary delay after repeated failed login attempts
Account blocking after repeated failed logins
Input validation using try-except
Username and menu-input normalization
Option to check remaining login attempts
🛠️ Technologies Used
Python
time module
Dictionaries and lists
Loops and conditional statements
Exception handling
▶️ How to Run
Install Python 3.
Download or clone this repository.
Open a terminal in the project folder.

Run:

python login_security_monitor.py
🧪 Project Scope

This is an educational project intended to practise Python programming and understand basic login-security concepts.

It uses predefined demo credentials and in-memory data. It is not production-ready authentication software.
